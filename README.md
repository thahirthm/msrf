# Elite Performance Hub

Below is a premium AI prompt that you can use in Lovable, v0, Replit AI, Figma AI, Claude, Gemini, Bolt.new, or any AI website builder. It is written to produce a luxury, modern, sports-oriented website instead of a generic academy template.

AI Prompt

Project Overview

Design a world-class, premium, modern sports academy website for a football academy. The design should be unique, immersive, and visually stunning—not a typical sports website.

The academy focuses on developing young football talent through professional coaching, modern infrastructure, international exposure, and partnerships with renowned football organizations.

A brochure will be provided. Use the logo, images, colors, content, achievements, contact details, and branding from the brochure wherever applicable.

The overall website should feel like a combination of Nike, Adidas Football, FIFA Academy, PSG Academy, and Apple-level minimalism.

Design Direction

Create a luxurious yet energetic website.

Avoid ordinary sports templates.

The website should immediately communicate professionalism, trust, discipline, and ambition.

The overall feel should be:

• Modern

• Premium

• Elegant

• Minimal

• Dynamic

• High-end

• Interactive

Every section should have subtle motion and smooth transitions.
